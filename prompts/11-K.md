# K｜審查與交付驗收

先讀[工作流程](../02-WORKFLOW.md)。在聊天框選擇 Claude Code 的 `/code-review` 或 Codex 的 `$code-review`，再加入以下內容。

```text
審查範圍：＜基準分支與提交，或指定目前工作區的路徑與已暫存、未暫存變更＞。
對照 AGENTS.md、規格、工作票及測試計畫，分別審查專案規範與需求實現。執行適用的回歸測試和使用者驗收，抽查至少一項關鍵需求連到測試斷言與實際結果。記錄未跑的檢查與原因。
回報阻塞問題與建議。驗證完成後，可在 docs/DELIVERY.md 或專案交付位置記錄版本、執行方式、驗證證據與剩餘風險。
```
